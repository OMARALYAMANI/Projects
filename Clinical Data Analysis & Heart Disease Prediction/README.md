## 📖 Overview

This project demonstrates an end-to-end machine learning pipeline for predicting heart disease using clinical data. Rather than focusing only on model training, the notebook walks through the complete data science workflow—from understanding the dataset to comparing multiple classification algorithms and evaluating their performance.

The goal of this repository is to showcase practical experience with **data preprocessing, exploratory data analysis, feature engineering, machine learning, and model evaluation**.

---

## ✨ What's Inside?

- 📊 Exploratory Data Analysis (EDA)
- 🧹 Data cleaning and preprocessing
- ⚙️ Feature engineering
- 📈 Statistical analysis and visualizations
- ⚖️ Handling class imbalance using **SMOTE**
- 🤖 Training multiple machine learning models
- 📉 Model evaluation and comparison
- 🏆 Selection of the best-performing model
