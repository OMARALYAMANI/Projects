# 📖 Overview

Finding available parking spaces is a common challenge for commuter students at KFUPM. This project proposes a smart parking solution that enables students to verify parking eligibility, locate available spaces, and improve the overall parking experience.

The project emphasizes the **Requirements Engineering lifecycle**, including stakeholder analysis, requirements elicitation, system modeling, and UI prototyping.

# 🎯 Project Objectives

The proposed system enables students to:

- 🚘 Check parking eligibility based on permit type
- 📍 View real-time parking availability
- 🏢 Navigate parking across a four-floor structure
- ⏱ Reduce the time spent searching for parking
